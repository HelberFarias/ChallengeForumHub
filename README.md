ForumHub API
📌 Sobre o projeto

ForumHub é uma API REST que simula o funcionamento de um fórum de discussões.
A aplicação permite gerenciar tópicos, relacionando-os a usuários e cursos.
O projeto foi desenvolvido com o objetivo de praticar a construção de APIs REST, persistência de dados e organização de aplicações backend utilizando Spring Boot.

⚙️ Funcionalidades

- Criar tópicos
- Listar tópicos (com paginação e ordenação)
- Buscar um tópico específico
- Atualizar tópicos
- Excluir tópicos

🛠️ Tecnologias utilizadas

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok
- Swagger (documentação da API)

🚀 Execução

1º Clone o repositório
2º Configure o banco de dados MySQL
3º Execute a aplicação
4º A API estará disponível em:

http://localhost:8080

Documentação Swagger:

http://localhost:8080/swagger-ui.html
